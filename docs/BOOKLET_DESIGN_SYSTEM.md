# 顔合わせしおりの設計方針

## 目的

しおりは情報を並べる資料ではなく、初対面の家族が自然に会話を始めるための小さな案内役にする。表紙に二人の名前を大きく置かない。表紙は、その日の空気・場所・二人らしい出来事を伝える入口にする。

## 作成体験

1. まず「冊子の型」を選ぶ。色ではなく、読み方・紙の開き方・情報の順番で選ぶ。
2. 選んだ型に必要な質問だけを表示する。不要な項目は表示しない。
3. 入力内容から、実際のページ順にプレビューを組み立てる。
4. PDFは冊子ごとの仕上がりサイズ・折り・綴じを前提に出力する。

## 冊子の型

### 1. ひまわりの約束

**形式:** A5中綴じ、8ページ。表紙はひまわり畑の思い出。

**読む順番:** 表紙 → ご挨拶 → ひまわり畑のプロポーズ → 陶芸体験 → 二人のプロフィール → 両家紹介 → これからの予定 → 結び。

**専用入力:** プロポーズの日付・場所・エピソード・写真、陶芸体験の場所・作ったもの・写真、今後の予定。

### 2. 藍の水引

**形式:** A4横二つ折り、4見開き。会食の進行と両家を品よく伝える。

**読む順番:** 表紙 → ご挨拶と当日の流れ → 両家の家系図 → 婚約・結婚指輪と今後の予定 → 結び。

**専用入力:** 乾杯する人、食事会の進行、家族の続柄、婚約・結婚指輪の紹介、入籍・挙式・新生活の予定。

### 3. 花とタッセル

**形式:** 正方形・紐綴じ、6ページ。特別な記念品として持ち帰る冊子。

**読む順番:** 花の表紙 → ご挨拶 → 二人の写真とプロフィール → 両家の紹介 → 会場案内とお品書き → 結び。

**専用入力:** 表紙の短い題、前撮りまたは思い出写真、プロフィール、会場写真、コース名、手土産。

### 4. レースの家族帖

**形式:** A4縦・手綴じ、8ページ。写真よりも文章と家族の人柄を中心にする。

**読む順番:** 表紙 → ご挨拶 → 二人のQ&A → 家族の人柄紹介 → 出会いの年表 → 会場案内 → 連絡先 → 結び。

**専用入力:** 二人への質問、家族ごとの会話ネタ、出会いの年表、会場アクセス、連絡先。

### 5. 紅白プロフィールブック

**形式:** A5中綴じ、12ページ。多くの情報を整然と載せる家族向け冊子。

**読む順番:** 表紙 → ご挨拶 → 当日の流れ → 新郎プロフィール → 新婦プロフィール → 二人の思い出 → 新郎家 → 新婦家 → 今後の予定 → 式場紹介 → 両家連絡先 → 結び。

**専用入力:** 詳細プロフィール、思い出写真、家族の似顔絵または写真、年表、式場案内、連絡先。

### 6. 写真アルバム

**形式:** A5中綴じ、12ページ。写真を主役にして、文章をキャプションとして扱う。

**読む順番:** 写真表紙 → ご挨拶 → 二人の写真年表 → 幼少期 → プロポーズ → 家族アルバム → 当日の案内 → 結び。

**専用入力:** 写真を複数枚、各写真の短いキャプション、幼少期の写真、プロポーズ、家族写真。

### 7. プロフィールマガジン

**形式:** A5中綴じ、12または16ページ。雑誌の特集のように、読み物として楽しむ。

**読む順番:** 表紙 → 編集後記風のご挨拶 → 写真特集 → 詳細プロフィール → 幼少期の思い出 → Love History → 結婚のコンセプト → 当日のタイムライン → 家族・ゲスト紹介 → メニュー → 会場案内 → 裏表紙。

**専用入力:** コンセプト、質問形式のプロフィール、年表、写真特集、家族紹介、メニュー、会場、SNSまたはQR案内。

## 実装原則

- 同じReactコンポーネントを色だけ変えて使い回さない。
- 冊子ごとに `pageProgram`、`inputSchema`、`printSpec`、`artDirection` を定義する。
- ページは必ず一枚ずつプレビューし、見開きが意味を持つ冊子は左右を対として表示する。
- 写真の枚数・比率・キャプションを冊子ごとに変える。
- 家族紹介は人数が可変。冊子により、家系図・似顔絵一覧・写真カード・短文紹介を使い分ける。
- PDF出力時はA4、A5、横開き、ページ数の倍数、折り線・綴じ代を管理する。
